# Правила проекта

Перед работой прочитай .memory/PROJECT.md и относящиеся к задаче авторитетные файлы:
.memory/MEMORY.md — факты; .memory/todo.json — задачи; .memory/adr/ — принятые решения.
Их краткий фрагмент доставляет расширение, полный источник читай по необходимости.
Текущее решение пользователя и проверенный код важнее пересказа памяти.
Обновляй файлы по ходу значимой работы. Не дублируй противоречащие текущие значения.
Источник и дата обязательны; вывод модели — гипотеза, а не принятое правило.
В ADR отделяй дословное основание от выводов [?]. Не придумывай альтернативы и последствия.
«Принято» не подтверждает весь текст ADR; при ответе «почему» сверяй основание с источником.
project_memory хранит вторичные свидетельства/версии; STALE требует перепроверки.
Для исправления записи используй тот же ID и expectedVersion. Commit доступен,
когда он полезен; для пустяков и неизменившегося состояния не вызывай его повторно.
Не изменяй архитектуру ради прохождения проверки. Архитектура и команды — PROJECT.md.
Перед UI-задачей прочитай .memory/DESIGN.md и найди существующие компоненты.
Если проверка/память отказала, сообщи ошибку; не объявляй проверенное выполнение.
Не коммить и не пушь без явной просьбы. Запуск и границы — .memory/README.md.
