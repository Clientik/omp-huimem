# Память проекта

Формат факта: текущее значение; источник (путь/версия или решение пользователя);
дата проверки. [?] — гипотеза, [!] — явно подтверждено пользователем; отсутствие
метки не означает подтверждения. Изменяй факт по месту, историю причины веди в adr/.
Записи SQLite не подменяют этот файл. После изменения документа они могут стать STALE.
