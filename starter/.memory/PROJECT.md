# Карта проекта

Заполнить по коду: модули и точки входа, разрешённые зависимости, команды тестирования.
Архитектурные решения с причиной: `.memory/adr/`. Актуальные факты: `.memory/MEMORY.md`.
Задачи: `.memory/todo.json`. Дизайн: `.memory/DESIGN.md`.
Машинные запреты задаёт человек в `.memory/architecture.json`; пустая настройка
не считается успешной архитектурной проверкой. Не придумывать инварианты для пустого проекта.
