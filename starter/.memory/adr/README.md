# Архитектурные решения

Записывай уже согласованные значимые решения без отдельного напоминания.
Формат NNNN-название.md: статус, дата, решение, основание (дословная цитата пользователя
или ссылка на первоисточник), способ проверки. Статус «принято» относится к решению,
а не ко всем предложениям документа. Несогласованное решение — proposed.
Альтернативы и последствия добавляй только при наличии источника. Если данных нет,
опусти эти разделы. Собственные выводы пиши отдельно с меткой [?] «не проверено»;
не приписывай их пользователю. При ответе «почему» цитируй основание, не догадку.
Пересмотр связывай ссылкой с заменённым ADR. Не объявляй предложение модели принятым.
