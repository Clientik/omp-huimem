# Архитектурные решения

Записывай уже согласованные значимые решения без отдельного напоминания.
Формат NNNN-название.md: статус, дата, контекст, решение, причина, альтернативы,
последствия, источник согласования, способ проверки. Несогласованное — proposed.
Пересмотр связывай ссылкой с заменённым ADR. Не объявляй предложение модели принятым.
