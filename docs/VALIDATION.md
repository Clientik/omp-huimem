# Что проверено

[На главную](i18n/README.ru.md)

## Автоматические проверки

28 тестов: 12 для хранилища, 8 для исходного адаптера и 8 для собранного расширения. Последние восемь повторяют проверки адаптера на bundle — это не 28 независимых сценариев.

Проверяются версии и история исправлений, отклонение неверных источников, устаревание, восстановление после открытия базы, конфликты версий, ошибки доступа, размер контекста, архитектурные запреты и отсутствие принудительных циклов продолжения.

Команда `bun run check` также проверяет manifest, наличие семи skills и отсутствие данных runtime в starter. GitHub CI проверяет, что сборка соответствует исходникам.

## Проверка с локальной моделью

Окружение: Windows, OMP 18.1.5, Bun 1.4.0, локальная Huihui-Qwen3.8-27B-abliterated-UD-Q4_K_XL.gguf, доступный контекст 65536. Облачный провайдер не использовался.

Четыре отдельных процесса OMP использовали одну проектную память без общей истории сессии:

| Сценарий | Результат | Время | Вызовы модели | Выходные токены |
| --- | --- | ---: | ---: | ---: |
| Сохранить PostgreSQL 17 и Stripe | Сохранено; две ошибки валидации исправлены моделью | 73,7 с | 8 | 2224 |
| Вспомнить в новой сессии | Правильный ответ | 6,0 с | 1 | 120 |
| Заменить Stripe на YooKassa | Та же запись, версия 2 | 69,8 с | 4 | 2396 |
| Вспомнить после замены | Правильный провайдер и причина | 5,7 с | 1 | 132 |

Это один успешный прогон, а не статистическая оценка надёжности. Для Stripe записанная причина повторяла выбор провайдера: проверка цитаты прошла, но полноценного объяснения «почему» это не доказывает.

Прямая загрузка собранного расширения и вызов `project_memory status` также прошли на реальной модели. Полная установка через GitHub пока не прошла приёмку. Пользовательские диалоги и рабочая база в репозиторий не включены.

## Что ещё нужно проверить

- Повторяемость на разных моделях и более длинных задачах.
- Реальное сжатие контекста с последующим воспоминанием.
- Прерывания и аварии процесса OMP во время работы.
- Параллельные сессии OMP и работа с ветками Git.
- Полный расход входных и выходных токенов относительно работы без плагина.
- Установка из GitHub на чистом окружении.

Отдельные unit-тесты конфликтов и восстановления базы не заменяют эти проверки целого OMP. Гарантий идеальной памяти, полной защиты архитектуры и фиксированной экономии токенов пока нет.
